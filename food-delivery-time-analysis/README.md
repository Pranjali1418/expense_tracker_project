# Food Delivery Time Analysis

An entry-level data analytics project using Python, pandas, SQLite, SQL, and Streamlit. It explores how traffic, weather, distance, city type, and delivery operations relate to food delivery time in a public India delivery dataset.

## Project question

Which delivery conditions are associated with longer delivery times?

## Current findings

- The dataset contains 38,964 delivery records. The source file is already cleaned; this project still standardizes text, removes duplicate rows, checks required analysis fields, and records how many rows remain.
- Average delivery time is **26.58 minutes**; the median is **26 minutes**.
- Average time is **21.50 minutes** when traffic is low and **31.44 minutes** in traffic jams.
- Average time rises from **22.42 minutes** for trips up to 5 km to about **30 minutes** for trips over 10 km.
- Distance and delivery time have a positive correlation of **0.322** in this dataset. This is an association, not proof that distance alone causes delays.

These are descriptive results from this dataset, not claims about every food delivery service.

## Run it on Windows

1. Install Python 3.10 or newer.
2. Open PowerShell in this project folder.
3. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

4. Install the one required package:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Run the analysis:

   ```powershell
   python analysis.py
   ```

The script creates `food_delivery.db` (SQLite), `results.json`, and four chart files under `assets/`. The database and charts are created locally so you can rerun the analysis after changing the code.

## Explore the SQL

Open `food_delivery.db` with [DB Browser for SQLite](https://sqlitebrowser.org/) or another SQLite viewer. Open `queries.sql`, copy a query into the SQL tab, and run it. The Python script also runs a few grouped SQL queries to produce chart data.

## Run the interactive Streamlit dashboard

After installing the packages listed above, run:

```powershell
streamlit run app.py
```

The app includes sidebar filters, interactive summaries, charts, SQL examples, a sample of the data, and a button to download filtered records. It reads the included CSV locally; if the CSV is missing, it downloads the public dataset from Hugging Face.

## Publish on Streamlit Community Cloud

1. Put `app.py` and `requirements.txt` in a public GitHub repository (or in a project subfolder of one).
2. In Streamlit Community Cloud, create a new app and choose that repository and branch.
3. Set the app file path to `app.py` (or `project-folder/app.py` if using a subfolder), then deploy.
4. When deployment finishes, share the public `*.streamlit.app` link.

## Files

- `index.html` — browser-friendly static project summary.
- `app.py` — interactive Streamlit dashboard.
- `analysis.py` — cleans the data, creates the SQLite database, runs SQL summaries, and creates SVG charts.
- `queries.sql` — extra SQL questions to try.
- `zomato_cleaned.csv` — dataset used by this project.
- `results.json` — current summary results for the project page.
- `assets/` — charts generated by the Python script.
